# 系统配置类思路笔记

对应代码:
- `src/main/java/com/lx/aisuperagent/config/CorsConfig.java`
- `src/main/java/com/lx/aisuperagent/AiSuperAgentApplication.java`

## 1. CorsConfig 的形成思路
- 真实需求: 前端页面（可能是不同域名/端口）访问 AI 接口时会遇到跨域限制。
- 方案:
  - 全局放行 `/**`。
  - `allowCredentials(true)` 允许携带 Cookie。
  - `allowedOriginPatterns("*")` 兼容多来源请求（避免 `*` 与 credentials 冲突）。
  - 开放常用方法和头，降低联调摩擦。
- 价值: 确保前后端联调阶段，接口可稳定访问。

## 2. AiSuperAgentApplication 的形成思路
- 真实需求: 提供统一 Spring Boot 启动入口，加载所有 Bean（LawApp、RAG 配置、工具、Agent 等）。
- 方案: 使用 `@SpringBootApplication` + `SpringApplication.run(...)`。
- 价值: 作为全项目装配中心，支撑全部业务组件自动注入与运行。
